# Latex Paper Writing Project

This is a Latex Paper Writing project for research papers.

## Project Structure

- `.out/`: All output files generated during compilation.
- `sty/`: Style files for the paper.
    - `graphics/`: Graphics used in templates.
    - `instructions/`: Instructions for using the templates.
    - `*.sty`: Style files.
- `figures/`: Figures used in the paper.
- `plots/`: Plots used in the paper, including uv configurations files and `*.ipynb` notebooks.
- `src`: Contains the main paper files.
    - `*.tex`: Additional sections or slides.
- `main.tex`: The main paper file.
- `main.bib`: Bibliography file for references.
- `.latexmkrc`: Configuration file for latexmk.
- `*.code-workspace`: VSCode workspace configuration files.
