# Latex Beamer Presentation Project

This is a Latex Beamer presentation project for research presentations.

## Project Structure

- `.out/`: All output files generated during compilation.
- `sty/`: Custom style files for the presentation.
    - `graphics/`: Graphics used in templates.
    - `instructions/`: Instructions for using the templates.
    - `*.sty`: Style files.
- `figures/`: Figures used in the presentation.
- `src`: Contains the main presentation files.
    - `*.tex`: Additional sections or slides.
- `main.tex`: The main presentation file.
- `main.bib`: Bibliography file for references.
- `.latexmkrc`: Configuration file for latexmk.
- `*.code-workspace`: VSCode workspace configuration files.
